## ✨ ویژگی‌ها

- 🔌 **یک دکمه، اتصال کامل:** بدون تنظیمات پیچیده، فقط بزن و وصل شو
- 🧭 **پیدا کردن خودکار مسیر:** اسکن هوشمند و انتخاب سالم‌ترین و سریع‌ترین مسیر
- 🔁 **اتصال مجدد سریع:** آخرین مسیر سالم رو یادش می‌مونه و دوباره اسکن نمی‌کنه
- 📱 **تونل‌سازی برنامه‌ها:** خودت انتخاب کن کدوم برنامه‌ها از فیلترشکن رد بشن و کدوم نه
- 🌐 **DNS دلخواه:** چندتا DNS آماده، به‌علاوه امکان اضافه کردن DNS دستی
- ⏸️ **قطع موقت از نوتیفیکیشن:** با یه لمس فیلترشکن رو موقتا خاموش کن و با یه لمس دیگه دوباره وصل شو
- 📊 **سرعت لحظه‌ای:** سرعت دانلود و آپلود همیشه توی نوتیفیکیشن جلوی چشمته
- 🏳️ **انتخاب کشور خروجی Psiphon:** فقط کافیه روی پرچم کشور بزنی
- 🛡️ **جلوگیری از نشت IPv6**
- 🧾 **لاگ کامل داخل برنامه:** حتی بعد از کرش هم لاگ قبلی رو نگه می‌داره
- 🔄 **آپدیت بی‌دردسر:** هر نسخه جدید مستقیم روی نسخه قبلی نصب میشه

## 🔐 پروتکل‌ها

| پروتکل | توضیح |
|:---:|:---|
| **WireGuard** | سریع و سبک، پیش‌فرض برنامه |
| **MASQUE** | ترافیک رو شبیه HTTPS معمولی می‌کنه (HTTP/2 و HTTP/3) |
| **Gool** | WireGuard داخل MASQUE، با آی‌پی خارجی |
| **Gool کلاسیک** | WireGuard داخل WireGuard |
| **MASQUE در MASQUE** | دو لایه MASQUE روی هم |
| **Tor** | شبکه Tor به‌صورت مستقل |
| **Psiphon** | سایفون به‌صورت مستقل |

همچنین می‌تونی **Tor** یا **Psiphon** رو کنار پروتکل اصلی، به‌عنوان **خروجی** یا **واسط** استفاده کنی.

## 📥 دانلود و نصب

1. برو به صفحه **[Releases](https://github.com/UCIRANX/UC-Guard/releases/latest)**
2. فایل مناسب گوشیت رو دانلود کن:

| فایل | مناسب برای |
|:---:|:---|
| `arm64-v8a` | ✅ تقریبا همه گوشی‌های امروزی |
| `armeabi-v7a` | گوشی‌های قدیمی ۳۲ بیتی |

3. نصب کن، دکمه اتصال رو بزن و اجازه VPN رو تایید کن. همین! 🎉

> 💡 اگه مطمئن نیستی کدوم رو بگیری، `arm64-v8a` رو نصب کن.

---

## 💡 چند نکته برای اتصال بهتر

- اگه وصل نشد، اول **پروتکل** رو عوض کن
- روی MASQUE اگه UDP بسته‌ست، **HTTP/2** رو روشن نگه دار
- اگه وصل میشه ولی مدام قطع میشه، **مبهم‌سازی** رو یه پله سنگین‌تر کن
- اگه اسکن طول کشید، نوع اسکن رو روی **turbo** بذار
- هر مشکلی بود، از صفحه **لاگ** داخل برنامه کپی بگیر و توی کانال تلگرام بفرست

## 📜 مجوز و قدردانی

UC Guard تحت مجوز **GNU AGPL-3.0** منتشر شده و کد کاملش در همین مخزن در دسترسه.
